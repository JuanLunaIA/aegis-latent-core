## 8. Acceptance Protocol (cla-assistant.io Compatibility)

To streamline contributions, this Project utilizes an automated verification system managed by **cla-assistant.io**. The system will scan your GitHub Pull Request and verify whether you have accepted the terms of this Agreement [CONTRIBUTING.md].

### Instructions for Signing the CLA

You can signify your binding acceptance of this Agreement through either of the following protocols:

#### Option A: Automated GitHub Integration (Recommended)
When you open a Pull Request against the Project repository, the `cla-assistant` bot will post a comment containing a link to authorize and sign this Agreement. Click the provided link, log in with your GitHub credentials, and click the **"Sign CLA"** button.

#### Option B: Pull Request Comment Sign-off
Alternatively, you may accept this Agreement by posting a comment directly on your GitHub Pull Request with the exact, verbatim text block below:

```text
I have read the Contributor License Agreement and I agree to its terms.
```

The automated system will detect this comment, parse your signature, and mark the Pull Request as cleared for review and merging [CONTRIBUTING.md]. 

By initiating either Option A or Option B, you represent that you have read, understood, and agreed to be bound by all of the terms, conditions, and license grants set forth in this Agreement.
