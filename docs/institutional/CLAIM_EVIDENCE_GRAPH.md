## Cross-document invariants

1. **No evidence inflation:** unit tests establish only the exercised code boundary; local measurements establish only the named workload.
2. **No formal inflation:** finite models do not prove implementation refinement or physical durability.
3. **No regulatory inflation:** technical contribution is not compliance, certification, authorization, admissibility, or auditor opinion.
4. **No topology inflation:** process-local ordering is not global ordering.
5. **No commercial inflation:** product hypotheses are not prices, customers, SLAs, support commitments, ROI, or production authorization.

A release fails if any institutional volume contradicts these invariants or the public claims matrix.
