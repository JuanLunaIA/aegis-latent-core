## Interpretation

A passing invariant test means only that the named executable or model check passed in its declared scope. It does **not** establish universal correctness, production fitness, compliance, certification, accepted capacity, cryptographic-module validation, or publication. The immutable published baseline is **v3.1.0**. The merged v4 source baseline is commit **`2050a310ec295afc61d033ff842c9a535a4f3105`**, with **14 synchronized `4.0.0` anchors**, and remains **unpublished**: no v4 tag, GitHub Release, or registry publication is asserted. A mutable checkout may differ from that anchor.
